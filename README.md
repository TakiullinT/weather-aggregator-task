# Weather Aggregator

Консольная утилита для получения текущей температуры в заданных городах и агрегации статистики по странам. Данные запрашиваются через публичный API `wttr.in`.

## Особенности реализации
* Написано на Python (3.10+).
* Использована только стандартная библиотека (`urllib`, `json`, `dataclasses` и т.д.) — **внешние зависимости не требуются**.
* Встроена защита от сетевых сбоев, таймаутов и непредвиденной структуры JSON.

## Входные данные
Скрипт читает список городов из текстового файла `cities.txt`, который должен находиться в корневой директории рядом с `main.py`. 
* Формат: один город на строку. 
* Пустые строки и дубликаты городов отфильтровываются автоматически.

**Пример `cities.txt`:**
```text
Moscow
Vienna
NhaTrang
```

## Запуск

python main.py
